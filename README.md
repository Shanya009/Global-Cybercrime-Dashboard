# Global Cybercrime Analysis and Intelligence Dashboard

## About the Project

The **Global Cybercrime Analysis and Intelligence Dashboard** is a data-driven application designed to analyze cybercrime incidents reported across the world over the past 25 years (2000–2024).

The project uses the **EuRepoC Global Dataset of Cyber Incidents** to explore historical cyber threats, identify patterns and trends, and present insights through interactive visualizations.

It transforms raw cybercrime data into meaningful graphical insights, helping users understand how cyber threats have evolved over time, which countries have been affected, and what types of cyber incidents have been reported.

## Key Features

- **Cybercrime Trend Analysis:** Explore how reported cyber incidents have changed over the years.
- **Threat Category Analysis:** Understand the different types of cyber threats and their frequency.
- **Country-wise Analysis:** Examine the distribution of reported cyber incidents across affected countries.
- **Interactive Data Filters:** Filter the dataset based on available parameters, such as year, country, and threat category.
- **Dynamic Visualizations:** View graphs and charts that automatically update according to the selected filters.
- **Data Exploration:** Access and examine the underlying dataset to gain deeper insights into reported cyber incidents.

## Objective

The main objective of this project is to make historical cybercrime data easier to understand through interactive data analysis and visualization. It aims to identify significant trends, highlight patterns in reported cyber incidents, and provide a clearer picture of the evolving global cyber threat landscape.

## Dataset

This project uses the **EuRepoC Global Dataset of Cyber Incidents**, which contains documented cyber incidents from 2000 to 2024.

Dataset source: https://zenodo.org/records/14965395

## Technology Stack

- **Python** – Core programming language
- **Pandas** – Data processing and analysis
- **NumPy** – Numerical operations
- **Streamlit** – Interactive dashboard development
- **Plotly** – Interactive graphs and visualizations
- **OpenPyXL** – Excel dataset handling

## Project Outcome

The final application provides an interactive platform for exploring historical cybercrime data, comparing reported threats across different years and countries, and understanding cybercrime trends through visual analytics.
